# قائمة مهام

مشروع تعليمي لأدهم مؤيد هاشم، مبني على الكود الحالي بدون إضافة مكتبات أو إطار عمل.

## التقنيات

HTML وCSS وJavaScript.

## ما الذي يقدّمه؟

إضافة المهام وإكمالها وحذفها وتصفية القائمة، وحفظها باستخدام localStorage.

## التشغيل

1. نزّل المستودع أو انسخه.
2. افتح `index.html` في متصفح حديث.
3. احتفظ بمجلدات الصور والملفات في مواقعها الحالية حتى تعمل المسارات.

## ملفات البداية

- `index.html`
- `script.js`
- `style.css`

## حدود المشروع

البيانات محفوظة في المتصفح نفسه فقط. مسح بيانات الموقع يحذفها؛ وعند تعذر التخزين تظهر رسالة ويستمر الاستخدام داخل الصفحة.

## مراجعة سريعة

جرّب الصفحة على شاشة هاتف، وتنقّل بلوحة المفاتيح، وتحقق من ظهور الصور وعمل الروابط. لا يحتاج المشروع تثبيت حزم.
